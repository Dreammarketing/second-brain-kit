# Second Brain Kit

Комплект воркшопу 1 майстер-групи **AI ЗАДРОТ**.

Ти збираєш свою базу знань і памʼять асистента: Obsidian, структура контекстів,
економія токенів, два двигуни памʼяті. Все локально, на своєму пристрої.

Для тих, хто не програміст. Кожен етап — окремий файл із готовим промптом,
який ти вставляєш у Claude Code і йдеш за ним.

---

## Як узяти собі

Натисни **[Use this template](https://github.com/Dreammarketing/second-brain-kit/generate)** →
**Create a new repository**.

- **Owner** — твій акаунт
- **Repository name** — `my-brain`. Саме так, щоб шляхи в комплекті збігались
- **Visibility** — обовʼязково **Private**

GitHub створить повну копію комплекту в твоєму акаунті. Це не форк:
звʼязку з оригіналом немає, історія чиста, усе всередині — твоє.

Далі клонуй свою копію на компʼютер. Якщо не знаєш як — етап 0 це зробить за тебе.

---

## Де що живе

Одне місце для всього, щоб через місяць не шукати по всьому диску.

```
~/ClaudeCodeProjects/            контейнер, тут живе все
~/ClaudeCodeProjects/my-brain/   база знань, вона ж сховище Obsidian
~/ClaudeCodeProjects/<проєкт>/   код кожного проєкту, поруч із базою
```

Код проєктів ніколи не кладеться всередину бази. Obsidian почне індексувати
службові файли й почне гальмувати, а git бази побʼється з git проєкту.

Робота завжди починається з папки бази:

```
cd ~/ClaudeCodeProjects/my-brain
claude
```

Запустив з іншого місця — агент базу не бачить. Це найчастіша помилка.

## Як користуватись файлом етапу

Відкриваєш файл. Верх — пояснення для тебе, людською мовою. Нижче межі —
промпт. Копіюєш промпт цілком і вставляєш у Claude Code одним повідомленням.

Claude веде по кроках і зупиняється після кожного. Не поспішай його підганяти.

---

## Три двигуни памʼяті — навіщо аж три

Вони не дублюють один одного.

**Obsidian** — це те, що читаєш ти. Свідомі нотатки, правляться руками.
Проєкти, клієнти, рішення, правила.

**iai-pme** — це те, що памʼятає асистент. Автоматично, дослівно, зашифровано,
без твоєї участі. Ти ніколи не пишеш «запамʼятай це».

**Graphiti** — це звʼязки і час. Не просто факт, а хто з ким повʼязаний,
коли це стало правдою і коли перестало.

Перший — для тебе. Другий — щоб не повторювати те саме щоразу.
Третій — щоб асистент бачив картину, а не список.

---

## Скільки це коштує

Obsidian, iai-pme — безкоштовно, все локально.
Graphiti — безкоштовний сам по собі, але витягує факти через модель,
тобто потрібен ключ OpenAI і кілька доларів на баланс.

## Безпека

Твоя база знань — це клієнти, цифри, домовленості. Репозиторій приватний.
Ключі живуть у `.env`, який ніколи не потрапляє в Git.

Етап 0 це налаштовує. Не пропускай його.
